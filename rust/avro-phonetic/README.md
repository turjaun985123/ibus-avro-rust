# Avro phonetic Rust core

This crate is the Rust migration of the Avro phonetic input engine. It ports the ordered transliteration patterns and contextual rules, the Bengali dictionary matcher, autocorrect mappings, suffix generation, Damerau-Levenshtein candidate ranking, remembered candidate choices, and the per-engine key/selection state machine. It includes a CLI frontend and an experimental `avro-phonetic-ibus` D-Bus service binary that adapts the core to IBus engine signals. The CLI accepts input on stdin or as arguments; the `suggest` subcommand prints ranked dictionary candidates; `--no-dictionary` disables dictionary suggestions.

The existing component descriptor and default package entry still launch the GJS service. The experimental Rust entry reads the same GSettings options, registers the Preferences property, and opens the existing preferences window when activated. GitHub Actions publishes the `avro-phonetic-ibus-linux-x86_64` binary artifact; stage the downloaded file at `rust/avro-phonetic/target/release/avro-phonetic-ibus` before installation to add that entry. Validating the adapter in a live IBus session remains outstanding. Legacy word data is embedded as generated UTF-8 JSON; source data remains canonical during migration. GitHub Actions owns all Rust builds and validation; do not run Cargo or local Rust builds.
